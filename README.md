Este es el repositorio correspondiente a la primera parte del proyecto, donde exploramos el modelo DNN e implementamos rotación, iluminación y oclusiones simuladas.
El archivo requierements.txt contiene las librerias necesarias en el entorno virtual.

El archivo tanhPolar.py es el que ejecuta el modelo DNN tradicional. Nota: El nombre del archivo es debido a que se intentó agregar una transformación tanhPolar, no se logró.
Ejecutar con python3 tanhPolar.py

El archivo detectorDNN.py es el que ejecuta el modelo DNN con las implementaciones antes mencionadas.
Ejecutar con python3 detectorDNN.py
